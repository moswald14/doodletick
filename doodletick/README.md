# Doodle Tick Keeper · 0.5.1b

Creator arcade, hourly color clock and Dot Wave mushroom garden for Home Assistant OS. This source-built app/add-on supports aarch64 and amd64.

The 0.5.1b update is in preparation; it has not been published or installed. It adds an explicit optional PublicNode Ethereum chain-1 read service while the connected wallet retains account access and message signing. Wallet reads remain the default, the service choice is not saved, and no on-load query or automatic fallback is added. Exact-block checks remain enforced. The operator receives the connecting IP, queried public address and block requests; smart-account checks also send the public digest/signature. See [wallet compatibility and disclosure](../keeper/WALLET-RECIPIENT.md).

Install through the [Doodle Tick repository](https://github.com/moswald14/doodletick), then open its Web UI through Home Assistant over HTTPS. Games and files pair directly between browsers with signed invitations, encrypted WebRTC and a spirograph comparison. No VPN is bundled. Direct reachability is required; no Internet relay is configured.

Read [DOCS.md](DOCS.md) and [HTTPS.md](HTTPS.md). Room directory codes and private garden trading work only for users of this same Keeper. Browser hosts and file holders must keep their pages open.

The global **Weather & music** panel adds optional city weather and original local soundscapes. Search/select a city manually, use C/F or Clear location, and start music with Play; hiding the tab pauses audio. City queries and selected coordinates go directly to Open-Meteo, without geolocation permission. Forecast attribution and the free service's non-commercial terms apply. See [weather and music controls](../keeper/README.md#weather-and-music).

A repository installation has separate data from a pre-existing local app. The [offline migration procedure](MIGRATION.md) preserves the witness, receipts and garden in a verified one-time import into an unused target. Earlier VPN state, when present, is preserved inert for rollback. Installing the repository alone does not migrate anything.

Private Keeper coins and public wallet DGT gardens have separate balances. Doodleverse Coin produces a separate prelaunch certificate with no balance or deployed DVC contract. The recipient flow links that certificate to a self-custody wallet through message signatures and fresh GPU work. It requests no funds, transaction fees, spending permissions, delegation or deployment. Existing vaults and v1/v2 records stay intact. DGT garden transactions are separate and require wallet confirmation and network fees; no shared deployed garden, redemption or token value is supplied. See [public-mode rules](../contracts/README.md).

The published 0.5b Home Assistant update was verified with the original Keeper witness, zero receipts and automatic-update setting preserved. Its 263 source checks and Chrome weather/music-control checks passed; audible output remains unverified. For 0.5.1b, all 287 app checks and repository checks passed. Chrome completed a disposable creator/mock-wallet proof using live PublicNode exact-block reads and real GPU work, then restored the public record without reconnecting or resuming work. Safe method/code diagnostics and no automatic fallback were also verified. Publication and installation remain pending; actual Coinbase signing and a complete live owner recipient proof remain unresolved. See [validation](../keeper/VALIDATION.md) for evidence and limits.
