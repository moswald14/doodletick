# MozCorp private rooms · 0.10b

## Install your rooms

Open **MozCorp** in Keeper and choose the matching private ZIP with **Choose private bundle**. Keeper checks its complete size, fingerprint and file inventory before activating it. A failed upload leaves the installed bundle intact. Use the ZIP prepared for this Keeper version; an unrelated or modified bundle is refused.

The public app contains a generic loader and the approved bundle fingerprint. Private station source stays in the separately installed bundle in Keeper's data. Rooms run in isolated, opaque-origin frames with no direct access to the parent app's storage or network. Home Assistant keeps its normal authenticated ingress. This isolation is not an independent security certification.

## Create, save and score a world

The authentic MozCorp machine and the separate playable Bug World use Keeper's creative project shelf. **Save world**, **Open**, **Export project** and **Import project** carry their supported state between sessions. Other desks retain their own local exports.

Projects are **unencrypted browser data**, separate from the encrypted vault. Keep portable exports of work you want to retain. The shelf is shared only within the same browser profile and origin; another browser, address or port needs explicit export/import.

**Edit soundtrack** opens the same project in Dot Studio. Save the edited score back to the project to carry it with the world. Original input, protected master, source mode and literal generated outputs remain separate fields. Reopening a project does not run the machine, turn held personal text into fiction or feed FINAL STORY // EXIT back into the hopper. The original cloud snapshot still excludes that final story; its literal text is kept separately in the project.

A legacy `.btwpkg` uses the actual Bug World importer, rather than being treated as a current-machine cloud save. The complete legacy payload is retained as inert JSON, including its original fields and source material. Embedded script text is never executed. Restored Bug World progress starts paused; press **Resume** when ready. Imports open a candidate room before replacing the active room, so a failed restore preserves the current work.

## Credits and Blooper Reel

The private machine keeps **13 · Voo Don't**, adds **14 · Credits** and **15 · Blooper Reel**, and retains its unnumbered hardwired **Story / Exit** at the end of the patch bay. The two added modules have independent switches and intensity controls.

Credits list the fictional cast and active machine crew. Blooper Reel uses only actual pre-story excerpts from Poem Gen, Telephone and Hivemind; intensity changes their count and length. It does not invent quotations or alternate endings. Empty, bypassed and duplicate takes are excluded. Personal, observer and talky source modes skip both cards.

The cards persist as literal outputs, separate from the source, protected master and final story. They never enter story feedback or change the Studio soundtrack.

## Keep desk boundaries intact

EVERYWHEN transfers only its approved fictional scene and creative icon cue. Sensations, notes, weather, receipts, full receipt hashes and synthetic RAM buffers stay outside that transfer. The cue travels through a one-use in-memory handoff; using its preview in the hopper remains an explicit action.

Integrity receives a separate one-use source-review handoff. An occupied notebook asks before replacement; cancellation keeps its notes and pending transfer. Integrity notebooks and CSV analysis are not captured in world projects. Use that desk's own exports for copies you want to keep. Other private desks likewise retain their own export controls.

Only the native Mozmoji dictionary and Voo Don't preferences persist through Keeper's preference bridge: `btw.mozmoji.fork.v1` and `btw.voodont.blind-backfeed.v1`, stored under `doodleverse-mozcorp-preferences-v1`. This does not grant a private frame access to other browser storage.

## News and the original site

**News Grabber** fetches headlines only after an explicit action. Keeper makes a bounded request to a fixed Google News RSS endpoint, then returns headline text and source links. A headline is source material, not verified evidence. Remote executable news scripts are not loaded into the rooms.

Use **Open original private site** for services belonging to that site, including private cloud savepoints, online HOPE-LON services and remote upgrades. The local integration does not silently write to those services or copy their authentication into Keeper.

## Contributor boundaries

Keep private station source out of the public repository and release assets. Update the approved fingerprint only after rebuilding and checking the matching private bundle. Preserve the narrow message contract, opaque frame policy, source-handling protections and distinction between project state and private desk exports.

Local source checks, disposable engine tests and simulated ingress checks establish only their tested behavior. They do not by themselves verify a physical Home Assistant installation, long playback or operation across separate devices.
